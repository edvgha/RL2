# RL2: Reinforcement Learning Algorithms

This project implements various Model-Free and Model-Based Reinforcement Learning algorithms using the `gymnasium` (formerly OpenAI Gym) library.

## Project Structure


- `src/model_free/`: Implementations of Q-Learning and SARSA.
- `src/model_based/`: Implementations of Policy Iteration and Value Iteration.
- `evaluate_model_free.py`: Script to train and evaluate model-free agents.
- `evaluate_vi_pi.py`: Script to run and compare VI and PI.
